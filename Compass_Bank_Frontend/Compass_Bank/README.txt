COMPASS BANK FRONTEND

Folder structure:
Compass_Bank/
  index.html
  css/
    style.css
  js/
    main.js
    appointment.js
    transactions.js

HOW TO RUN:
1. Extract the ZIP file.
2. Open the Compass_Bank folder in VS Code.
3. Open index.html with Live Server, or open it directly in your browser.

NOTES:
- Tailwind CSS and Google Fonts are loaded from their CDNs, so an internet connection is needed for those styles/fonts.
- This is still a frontend demonstration. Appointment lookup, editing, cancellation, and reference generation are not connected to a database or backend.
- Appointment and transaction values are not persistently saved yet.
